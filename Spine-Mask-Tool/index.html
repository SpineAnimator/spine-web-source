Spine export: one clipping attachment, placed immediately before the target region slot with end set to that slot. Existing JSON skeletons are retained, including bones, skins and animations.

For image-only input, save both JSON and image.png; put PNG in the Spine images/ folder. For existing JSON, select the exact region PNG; a packed atlas sheet is not a region. Binary .spine requires conversion by a licensed Spine Editor and is not silently replaced by a new skeleton.

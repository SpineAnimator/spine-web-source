Install Bridge
Bridge setup

Download and open the installer for your operating system:

  • Windows: download the EXE and double-click it.
  • macOS: extract the ZIP and double-click INSTALL.command.
  • Linux: extract the TAR.GZ and double-click INSTALL.desktop.

The installer registers the local host, prepares a dedicated browser profile and loads the extension automatically. No terminal commands, Python setup, developer mode or manual extension loading are required. The original Chrome profile is not modified.

Save the Spine project before importing it. The bridge reads the saved project and its referenced images, not unsaved editor memory. macOS Gatekeeper or Windows SmartScreen may show the standard OS confirmation because the installers are not signed with a paid publisher certificate.

Native render details

Only mask geometry and the already alpha-protected second image are submitted through a private, short-lived Cloudflare handoff to licensed Spine Editor GitHub Actions, when you press Render. Source artwork stays local.

Export details

One clipping attachment is inserted before the selected region slot and ends at that slot. Existing bones, skins and animations are retained.

The Spine ZIP contains the alpha-protected second image; geometry JSON alone cannot hide connector pixels under an opaque texture. For image-only input, use JSON and image.png in the Spine images/ folder. A packed atlas sheet is not an individual region; binary .spine must be converted with licensed Spine Editor.
